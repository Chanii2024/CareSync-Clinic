# CareSync-Clinic | Digital Health Ecosystem

**CareSync** is a modern, premium healthcare ecosystem designed to streamline interactions between patients, doctors, and clinic staff. Built with a focus on responsiveness, safety, and visual excellence...

---

## Key Features

### Patient Portal
- **Dashboard:** Instant overview of vitals, heart rate, and upcoming visits.
- **Smart Booking:** Real-time appointment scheduling with preferred doctors.
- **Health Records:** Secure, digital repository for medical reports and history.
- **Billing:** Transparent digital invoicing and payment history.

### Professional Suites
- **Doctor's Daily Queue:** Manage patient intake and daily schedules efficiently.
- **Nurse Workflow:** Digitally track vitals, vaccine schedules, and patient intake.
- **Receptionist Dashboard:** Centralized calendar and counter payment management.
- **Pharmacist Inventory:** Safety-first dispensing and inventory tracking.
- **Admin Control Center:** Robust user management and audit logs.

---

## Tech Stack & Design
- **Core:** HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Design System:** Inter Typography, Font Awesome Icons, Custom Design Tokens.
- **Hosting:** Firebase Hosting.

---

## Getting Started

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/Chanii2024/CareSync-Clinic.git
   ```
2. Navigate to the `WebApplication` folder.
3. Open `index.html` in your browser.

### Deployment
To deploy the application to Firebase Hosting:
```bash
cd WebApplication
firebase deploy --only hosting
```

## Security & Safety
- **No Private Keys:** All configurations are managed for public client-side deployment.
- **Git Safety:** Sensitive files, logs, and temporary caches are excluded via `.gitignore`.
- **Form Validation:** Every input is strictly validated on the client side for data integrity.
